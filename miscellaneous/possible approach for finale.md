Install infrared sensor at an angle of about 70° diagonally facing the houses wall.
x = measured value of sensor


If x measures wall being in right angle:
    drive parallel to wall until x changes or colure sensor detects red.

If x changes and sensor reads value indicating no object:
    turn right until x is the value as when wall is parallel. Then drive parallel to wall until x changes or colure sensor detects red.

If x changes and sensor still reads value indicating an object:
    turn left slowly until x is same value as when parallel wall is seen.
